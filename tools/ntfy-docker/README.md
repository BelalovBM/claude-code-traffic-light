# Свой сервер ntfy в Docker

Сервер для Claude Code Traffic Light: закрытый по умолчанию, с одним пользователем и ровно теми правилами доступа, которые нужны программе. Данные лежат в томе Docker и переживают перезапуск и обновление образа.

## Запуск

```powershell
cd tools\ntfy-docker
.\setup.ps1
```

Скрипт можно запускать повторно. Он:
1. определяет адрес этого компьютера в локальной сети и записывает его в `.env` (или берёт `-BaseUrl`);
2. создаёт том `claude-ntfy-data` (данные старого тестового сервера `tl-ntfy-data` переносятся один раз, тестовый контейнер заменяется);
3. запускает контейнер `claude-ntfy` с перезапуском вместе с Docker и ждёт, пока он станет здоровым;
4. создаёт пользователя (по умолчанию `phone`), если его ещё нет, и показывает пароль **один раз**;
5. выставляет правила: `ccl-*` — чтение и запись для пользователя, `ccr-*` — чтение и запись для пользователя и только запись для всех остальных (кнопки «Разрешить» и «Запретить» на телефоне не умеют входить в аккаунт).

Параметры: `-User имя`, `-Port 18081`, `-BaseUrl https://ntfy.example.org`, `-Token` (ещё и создать токен доступа `tk_…`).

## Подключение

- **Программа:** Настройки → Телефон → «Свой сервер ntfy»: адрес, пользователь, пароль (или токен в поле пароля, пользователь пустой).
- **Телефон:** приложение ntfy → Настройки → Пользователи → добавить тот же адрес, имя и пароль; потом подписаться по QR-коду со страницы «Телефон».

## Откуда телефон достанет сервер

- **Домашняя сеть.** Адрес вида `http://192.168.x.x:18081` работает, пока телефон в той же сети Wi-Fi. Windows может спросить про брандмауэр; если телефон не достаёт сервер, разрешите входящие подключения на порт 18081 для профиля «Частная сеть».
- **Из интернета.** Нужен адрес с HTTPS (свой домен и обратный прокси или туннель) — запустите `.\setup.ps1 -BaseUrl https://ntfy.example.org -Port 8080` и направьте прокси на этот порт. Без HTTPS не выставляйте сервер в интернет: пароль пойдёт открытым текстом.

## Обслуживание

```powershell
docker compose ps                    # состояние
docker logs claude-ntfy              # журнал сервера
docker compose pull; docker compose up -d   # обновить образ
docker compose down                  # остановить (данные остаются)
docker exec -it claude-ntfy ntfy user change-pass phone   # сменить пароль
```

Резервная копия: том `claude-ntfy-data` содержит `user.db` (пользователи) и `cache.db` (сообщения). Том создан вне проекта, поэтому `docker compose down -v` его не удаляет.
